From 0 to 0Day on Symbian
Whitepaper · 2009 · Pwnie Award Winner

Demonstrated that classic vulnerability analysis and exploitation techniques are feasible on Symbian OS smartphones, despite OS obscurity and lack of tooling. Showed how to find low-level vulns in Nokia phones exploitable via MMS.

"We identified seven vulnerable multimedia codec DLLs on Nokia devices (E61, E71, N96) that could be triggered remotely via a single MMS message. The attack surface of Symbian phones turned out to be surprisingly similar to desktop systems — the same classes of bugs, the same exploitation primitives, just packaged in a less familiar binary format." — From 0 to 0Day on Symbian, SEC Consult Whitepaper, 2009

Improved DNS Spoofing Using Node Re-Delegation
Whitepaper · 2008

A technique to make DNS cache poisoning more reliable. SEC Consult was among the first to write a working "fast cache poisoning" exploit after Dan Kaminsky's coordinated multi-vendor disclosure.

"By combining the birthday attack with node re-delegation, we reduced the average time to poison a DNS cache from hours to under a minute. The technique bypasses the source port randomization defense that most resolvers had deployed as a countermeasure." — Improved DNS Spoofing Using Node Re-Delegation, SEC Consult, 2008

★
Mythril
Creator · 4,200+ stars

Pioneering open-source security analysis tool for EVM bytecode. Uses symbolic execution, SMT solving, and taint analysis to find vulnerabilities in Ethereum smart contracts. Called "the nmap of Ethereum."

"Mythril operates directly on EVM bytecode, building a control flow graph and exploring execution paths symbolically. For each path, it constructs a set of constraints that are fed to an SMT solver. If the solver finds a satisfying assignment that triggers a security property violation — say, an unchecked CALL to a user-controlled address — it reports a concrete exploit." — Smashing Ethereum Smart Contracts for Fun and ACTUAL Profit, HITB 2018
GitHub Announcement 4,200+ stars

Hound
Creator · 716 stars · arXiv Paper (Oct 2025)

Language-agnostic AI code security auditor that builds adaptive knowledge graphs for deep iterative reasoning. Two-model architecture (junior agent + senior guidance). On ScaBench: 31.2% micro recall vs 8.3% baseline.

"We introduce Hound, a multi-agent system that constructs relation-first knowledge graphs to reason about complex software systems. Unlike single-pass LLM auditors, Hound's junior agent explores code iteratively, building a structured representation of data flows, trust boundaries, and invariant assumptions. A senior model guides exploration strategy, pruning false paths and amplifying signal — achieving a 3.7x improvement in vulnerability recall over baseline approaches." — Hound: Relation-First Knowledge Graphs for Complex-System Reasoning in Security Audits, arXiv:2510.09633

Observer Patch Holography — A Theory of Everything
Theory of Everything · Paper · Book · Framework · 2025–2026

Observer Patch Holography (OPH) is a theory of everything that unifies quantum mechanics, general relativity, and the Standard Model from four information-theoretic axioms. OPH derives Lorentz invariance, Einstein's field equations, quantum entanglement, gauge symmetry (U(1) × SU(2) × SU(3)), and the holographic principle as necessary consequences — not assumptions. The framework resolves the black hole information paradox, explains dark energy as an observer-patch boundary effect, and predicts novel signatures testable with current technology. Published as the preprint "Observer Patch Holography" and the book "Reverse Engineering Reality."

"What if spacetime isn't fundamental, but emergent? We start from four information-theoretic axioms — finite information density, observer-local patches, holographic encoding, and consistency under patch overlap — and show that the familiar physics of general relativity and quantum mechanics drops out as necessary consequences. The universe, in this view, is a self-consistent error-correcting code." — Reverse Engineering Reality: Observer Patch Holography as a Theory of Everything, 2025
"Observer Patch Holography derives all known fundamental physics — general relativity, quantum field theory, and the Standard Model gauge group — from four axioms about information. This is not a modification of existing theories but a derivation from deeper principles, making it the first framework to achieve genuine unification from information-theoretic first principles." — Observer Patch Holography, Zenodo, 2025 (DOI: 10.5281/zenodo.18288114)
